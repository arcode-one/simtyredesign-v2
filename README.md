# СИМТИ — точный редизайн v2

Новый интерактивный frontend-прототип, собранный после повторного аудита `app.simty.ru`.

В этой версии не добавлены новые продуктовые разделы или функции. Структура следует текущей платформе, а изменения ограничены визуальной системой, компоновкой компонентов, состояниями и адаптивностью.

## Сохранённый функционал

- личный раздел: «Начать беседу», «Друзья», «Избранное»;
- добавление друга и вкладки «Все», «Входящие», «Исходящие»;
- серверы и каналы;
- создание сервера, текстового/голосового канала и категории;
- приглашение друзей на сервер;
- настройки пользователя: профиль, голос и видео, устройства;
- настройки сервера: профиль, приватность, роли, участники, приглашения, заявки, аудит и удаление;
- настройки канала: информация, разрешения и удаление;
- предупреждения перед выходом, удалением канала и удалением сервера;
- матрица прав ролей и канала с состояниями «разрешить / по умолчанию / запретить»;
- выбор роли или пользователя в разрешениях канала;
- фильтры заявок «Все / Ожидают / Одобрено / Отклонено» и ручное обновление;
- карточка участника по нажатию в списке сервера;
- меню уведомлений канала на кнопке `@`: все сообщения, только упоминания, временное отключение и полное отключение;
- раскрывающийся фильтр журнала аудита по разрешениям, сообщениям, каналам, серверу, участникам, звонкам и файлам;
- микрофон, звук, вложение, стикеры и голосовое сообщение;
- панель беседы: медиа, записи и файлы.

## Подготовка к Figma

Сначала перенесите цветовые tokens в Variables, затем соберите компоненты `RailItem`, `NavRow`, `ChannelRow`, `UserPanel`, `Button`, `IconButton`, `Input`, `Tabs`, `Message`, `Composer`, `Modal` и `SettingsLayout`. Экраны прототипа уже построены из повторяемых компонентов и подходят как основа для макетов.

Прототип использует демонстрационные данные и не подключён к API рабочей платформы.
